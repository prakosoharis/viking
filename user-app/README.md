# User App - Invoice Upload

Aplikasi untuk user upload invoice/receipt.

## 🚀 Run

```bash
npm run dev
```

Port: **http://localhost:3000**

## ✨ Features

- Login dengan nomor HP
- Upload multiple images (drag & drop)
- Validasi file (JPG, JPEG, PNG only)
- Success modal
- Upload history

## 🎨 Design

- Blue gradient background
- Clean & simple
- Mobile-first responsive
- Smooth animations
