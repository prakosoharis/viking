# Admin App - Invoice Manager

Aplikasi untuk admin manage semua uploads.

## 🚀 Run

```bash
npm run dev
```

Port: **http://localhost:4000**

## 🔐 Login

- Username: `admin`
- Password: `admin`

## ✨ Features

- Secure admin login
- View all users with uploads
- Expandable user view
- See all images per user
- Upload statistics

## 🎨 Design

- Purple gradient background
- Professional & clean
- Responsive layout
- Smooth animations
